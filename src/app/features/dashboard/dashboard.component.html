¿Cómo usar el sistema?

  1. Explorar: Navega a la sección de Recursos para ver qué está disponible
  2. Seleccionar: Elige el recurso que deseas reservar
  3. Reservar: Completa el formulario con la fecha y hora deseada
  4. Confirmar: Tu reserva se confirmará inmediatamente
  5. Gestionar: Ve a "Mis Reservas" para modificar o cancelar tus reservas
